# Galaxia para Valeria

Sitio estático interactivo listo para abrir localmente o publicar en Vercel.

## Vista previa

Abre `index.html` en el navegador. Para una vista previa más fiel, abre esta carpeta con VS Code y usa Live Server.

## Personalización

- Nombre, colores y dedicatorias: edita `window.GIFT_CONFIG` al final de `index.html`.
- Distribución, corazón, sensibilidad del arrastre y animaciones: edita `galaxy.js`.
- Ramos amarillos: reemplaza los archivos de `assets/` conservando sus nombres.

## Publicación en Vercel

Puedes arrastrar esta carpeta al panel de Vercel o ejecutar `vercel --prod` desde su interior.
